# GIF Frame Viewer for Edge

一个基于 Manifest V3 的 Edge 扩展，用于在网页中查看 GIF 的每一帧。

## 使用

1. 打开 `edge://extensions`，开启右上角的“开发人员模式”。
2. 点击“加载解压缩的扩展”，选择本目录。
3. 打开包含 GIF 的网页，GIF 下方会自动出现逐帧控制条，不需要点击插件图标。

扩展更新后需要在扩展管理页点击“重新加载”，并刷新已经打开的网页标签页。若要在本地 `file://` 页面使用，还需在扩展详情中开启“允许访问文件网址”。

查看器支持动画 GIF 和动画 WebP，解析完成后自动播放，并提供播放/暂停、上一帧/下一帧、跳到首帧/末帧、默认开启的循环播放、时间进度条，以及 0.25x 到 4x 的播放速度。拖动进度条可暂停并跳转到对应时间和帧；长按上一帧或下一帧按钮可连续步进。GIF 在 Edge 不支持 `ImageDecoder` 时会使用内置后备解码器。

快捷键默认生效：空格播放/暂停，`←`、`→` 暂停并逐帧后退/前进。包含多个动画图片时，快捷键默认控制第一个查看器；鼠标移到其他图片或控制条后会切换目标。

在花瓣网中，扩展仅在 URL 含有 `modalImg` 参数的图片查看模式启用，并只处理与该参数对应的主图。首页、发现页、画板页和相关推荐图片不会启用查看器。

进入普通 `/pins/{id}` 页面后，扩展会在空闲时静默预加载主图。关闭 `modalImg` 查看器回到同一个 pin 时保留缓存，再次打开可直接复用；离开该 pin 页面或进入另一个 pin 时自动清除缓存。原始图片最多缓存 3 个或 50 MB，完整解码帧最多缓存 1 个或 150 MB。

花瓣 SPA 路由通过 Navigation API 事件驱动检测，主图变化仅监听 `src` / `srcset`，连续 DOM 事件会合并到一个动画帧处理。GIF 解码在 Web Worker 中执行，离开 pin 并清空缓存后会终止空闲 Worker。

扩展优先使用 Edge 的 `ImageDecoder` API 读取动画帧。若网页资源因跨域策略无法读取，查看器会显示错误提示；将图片下载到本地后可使用 Edge 内置图片查看器查看。
